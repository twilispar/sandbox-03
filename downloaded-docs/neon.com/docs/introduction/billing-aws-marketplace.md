# AWS Marketplace

Paying for Neon via your AWS Billing account

**Important: Deprecated**

Neon no longer supports billing through the AWS Marketplace.

Neon [self-service pricing plans](https://neon.com/pricing) are no longer purchasable through the AWS Marketplace. You can only purchase these plans through Neon.

If you have any questions about billing in general or require assistance, please reach out to [Neon Support](https://neon.com/docs/introduction/support).
